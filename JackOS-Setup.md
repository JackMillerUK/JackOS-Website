Welcome To JackOS. 

Read this file to understand how to set up JackOS for v5 Beta 3 onwards. 

Requirements:

The JackOS System Requirements are:

-An active internet connection during setup and during use for online features.
-The Microsoft Edge Browser (Safari does not work and Google Chrome is yet to be supported).
-Visual Studio Code.
-A Mac or PC.
-Visual Studio Code connected to the GitHub repository.


JackOS Boot:

To boot JackOS, you first need to go to Visual Studio Code with GitHub connected, choose Terminal, then type the command: python3 -m http.server 1234 (1234 is a placeholder port number).

Then, go to Edge and go to this url: http://localhost:1234/JackOS-System-Files/JackOS.html

JackOS Setup: 

This section describes how to setup JackOS.

1: Type in either your custom activation key (required for features such as cloud sync) or put in GUES-TACT-IVAT-ION. Notice: This free activation key loses some features! Then click Activate.

2: Either, choose yes, click the admin user, put in the admin's password and then go straight to login or click No/Nothing if nothing appears. 

3: If nothing appeared or you clicked No, you will be at a JackOS Setup page where you create a user, make a password, then confirm the password. Create as many accounts as needed (including guests), with the first being admin and more can be added later and the permissions can be changed later too.

4: You will appear at a security question setup page where for the said user, pick 3 questions, answer them (required to reset your account later) and then go to login after all accounts are done.

JackOS Login

Should the last steps be followed, you will be at an login page. Choose the account, type the password if the account chosen isnt Guest and log in.


Well Done! You have now set up JackOS!
