# Security Policy

## Supported Versions

These Versions are currently supported for security updates:


| Version | Supported          |
| ------- | ------------------ |
| 5 Beta   | :white_check_mark: |
| 4.0+   | :white_check_mark:                |
| 3.2+   | :white_check_mark:                |
| <3.2    | :x:                |

## Reporting a Vulnerability

If you notice an error or a bug in the code that can makes the software vulnerable, contact me on Github using discussions or however feels right to you.

Updates for these errors usually come out within 1-2 weeks.

However, if this error is critical like a security problem, the fix for this comes out within 5 working days.
