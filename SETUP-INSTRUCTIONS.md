NOTE: IF YOU WANT A PRO/PRIVATE VERSION, YOU WILL HAVE TO GIVE ME THE USERNAME AND PASSWORD YOU WOULD LIKE TO USE! YOU WILL THEN RECEIVE A FILE THAT WILL ACTIVATE THESE VERSIONS. THE PASSWORDS CAN BE CHANGED ONCE INSTALLED!

Once you have activated JackOS, you’ll be asked to add an account. You can make your own account, for example, “John Appleseed”. You will be asked to fill in 2 more fields. 

This will ask you to make your own password and then confirm your password. 

NOTE: THE FIRST ACCOUNT YOU ADD WILL BE THE ADMINISTRATOR. THIS CAN BE CHANGED LATER.

Then, there will be security questions. This is so if you forget your password, you can reset your password.

Put in your account details (the JackOS one) and you’ll be logged in.

NOT ALL CODE PREVIEW APPLICATIONS WILL BE SUPPORTED FOR SOME FEATURES. FOR ALL FEATURES TO BE WORKING FINE, YOU CAN USE Visual Studio Code SINCE JackOS IS BUILT ON Visual Studio Code.
