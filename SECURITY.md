# Security Policy

## Supported Versions

These Versions are currently supported for security updates:


| Version | Supported          |
| ------- | ------------------ |
| 5   | :white_check_mark: |
| 5 Beta (Any Version)  | :white_check_mark:                |
| 4  | :white_check_mark:                |
| <4.0   | :x:                |

Please understand that systems running the supported JackOS versions are eligible for security updates. For example, if v3 was eligible, that means that if v3.3.5 or something had a bug and it was reported, JackOS v3.3.6 or any other higher number may contain that fix.

## Reporting a Vulnerability

If you notice a bug in the code that can makes the software vulnerable, buggy or less strong from attacks, contact the JackOS Team on Github using GitHub discussions or via the JackOS Report A Bug app inside of JackOS (COMING SOON).

Updates for these bugs usually come out within 1-2 weeks from the initial report.

However, if this error is critical that could make the software vulnerable, the patch for this comes out within 5 working days.

## About The JackOS Beta Program

JackOS Beta is a voluntary program that allows users to install major updates before the public release. However, data loss is not covered and Beta may be buggy.

JackOS Is Completely Free To Use With Free Upgrades That Require Contacting The JackOS Team.

<details>
  <summary>Does JackOS Track The Users Or Steal Data?</summary>
  <br>
  No, JackOS Does Not Track The User Or Steal Any Data. Whilst It Uses The Camera And Connects To A Server, All Data Is Stored Locally And Not Published To The Server Unless Enabled By The User. Even Then, JackOS Does Not Track The User.
</details>
<details>
  <summary>How Do I Upgrade My JackOS Edition?</summary>
  <br>
  You Can Contact The JackOS Team Via GitHub Discussions And The Help Centre There Can Assist You With The Upgrade.
</details>
<details>
  <summary>Do I Get Paid For Testing Beta Versions Of JackOS?</summary>
  <br>
  No. JackOS Beta Is Fully Voluntary And Doesn't Cost Anything, Neither Does It Pay Anything.
</details>
<details>
  <summary>How Do I Contact The JackOS Team?</summary>
  <br>
  Go To The Discussions Page, Choose A Appropriate Discussion Or Create A New One. Post Your Problem And Someone Will Get Back To You Within 72 Hours.
</details>

<details>
  <summary>What Are The JackOS System Requirements And How To Launch It?</summary>
  <br>
  For JackOS To Run To It's Best Ability, You Will Need A Mac Or PC With Visual Studio Code Installed And Microsoft Edge. Then Clone The JackOS Repo, Put In The Terminal Command: python -m http.server 1234 Or python3 -m http.server 1234 Depending On Your Device. Go To Edge And Go To The URL: localhost:1234. Then, Depending On Your JackOS Version, Click JackOS-Website.html and follow the instructions to install or go to JackOS-System-Files then JackOS.html. Both Ways Launches The Latest Available Version At That Given Time.
</details>
